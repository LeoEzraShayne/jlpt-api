## 已核对的数据事实和建议分类

Play 的收集范围包括第三方 SDK 及应用控制的网页行为；不能只填写原生 Activity。设备内处理可以不作为远程收集，但相关导出/第三方传输仍须按实际方式判断。[Google 数据安全定义](https://support.google.com/googleplay/android-developer/answer/10787469?hl=en)

| 数据安全类型 | 代码所见事实 | 目的与填写边界 |
| --- | --- | --- |
| 个人信息：姓名、邮箱、用户 ID | Google OAuth 请求 `email/profile`，API 保存显示名称、邮箱、Google provider ID、应用 user ID | 账号管理、应用功能；学习主功能需登录。不能因 OAuth 而勾选“不收集” |
| 照片：头像 | 保存 Google `avatarUrl`，有头像时由页面显示；没有发现 JLPT 原生相册上传 | 账号展示。需覆盖头像这一实际资料；不能将无相册权限等同于无照片资料 |
| 应用活动：应用互动、其他用户生成内容 | 保存级别、计划、偏好、练习、造句、修改、收藏、批改和复习历史；API 存储非临时 | 应用功能、学习个性化；句子/场景及必要上下文发送 AI。没有发现公共帖子、私信或通讯录功能，不把练习误填作用户间消息 |
| 财务信息：购买记录 | 订单 ID、商品、金额、币种、支付/退款状态、权益、Google token、奖励交易记录 | 应用功能、防欺诈/安全、对账。完整银行卡由 Stripe/Google 支付流程处理，不存于 JLPT 数据库；仍不能宣称没有财务数据收集 |
| 设备或其他 ID | 原生 session、混淆后的 Play account ID、SSV alias；广告 SDK 默认还处理广告 ID/app set ID 等 | 账号关联、功能、安全；SDK 广告相关用途需另列。混淆/哈希不自动排除数据披露 |
| 大致位置、互动、诊断、设备 ID（广告路径） | Next-Gen SDK 官方说明默认收集和分享 IP、互动、诊断、广告/设备及部分账号相关标识 | 广告、分析、防欺诈；IP 可用于大致位置。以最终 SDK 和初始化路径核验，不能把“非个性化广告”写作零收集 |
| 音频、文件/文档、其他用户生成内容（旧服务） | 恢复页读取三类旧草稿和 `recordings/*.m4a`，本地播放、用户主动 CreateDocument 导出 | 恢复页自身无 API 上传；用户选择云端文档提供商时可能由其同步。旧网页本身的数据处理仍需独立核验，不能从本地恢复模块推导整个旧服务“不收集音频/照片” |

SDK 官方明确其默认数据类型及 TLS 传输；本项目使用 `ads-mobile-sdk:1.4.0`，最终合并 manifest 还需按实际 AAB 复查。[Next-Gen 数据披露](https://developers.google.com/admob/android/next-gen/privacy/play-data-disclosure)

“分享”不应直接全部选否。AI 服务、广告 SDK 和支付/托管应分别评估；只有满足 Play 的服务提供商、明确用户操作等例外条件，才可适用例外。没有依据宣称第三方完全不保留内容或不用于改进模型。

**Gemini 免费层的具体差异：** 当前免费优先策略应披露免费层可能使用输入/输出改进 Google 服务，并由人工审核；不是付费数据处理承诺。必须区分：Age Requirements 对所有 Gemini API 客户端（免费和付费）限制指向或很可能被未满 18 岁人群访问的服务；付费不能消除年龄限制。向 EEA、英国、瑞士提供 API 客户端时的限制才是 paid-only。不能仅在商店选择“18+”就假定现有无年龄校验的所有路径已满足要求，也不能为解决此问题擅自开通付费。[Gemini 条款](https://ai.google.dev/gemini-api/terms)

可执行整改建议（仅方案，不改市场/生产配置）：

1. 保留合资格请求的“Gemini 免费优先，耗尽/失败转 DeepSeek”。在共享 AI 路由前新增服务端 eligibility 判断，覆盖语法批改、词汇生成/批改及后台重试；不适用免费 Gemini 的请求直接走 DeepSeek，不计一次失败 Gemini 尝试，也不新增长期付费。

3. 对受众层面的限制不能仅靠逐请求路由自动认定已经解决。应核对该 API client 的定位、真实可访问人群，以及隔离后的成人/合资格路径是否满足条款。DeepSeek 本身也有年龄/监护人及使用限制，不能宣称转发后儿童适用问题自动消失；按其实际 Open Platform 条款完成确认。[DeepSeek 平台条款](https://cdn.deepseek.com/policies/en-US/deepseek-open-platform-terms-of-service.html)、[使用条款](https://cdn.deepseek.com/policies/en-US/deepseek-terms-of-use.html)
4. 在学习提交前补清楚的 AI 处理说明及必要同意，记录政策版本；去掉不必要的姓名/邮箱/user ID 等提示内容，检测/提示敏感输入，不宣称检测能保证清除所有个人信息。所有资格组合须有“不会调用 Gemini”的路由回归，并保留原 DeepSeek 成本预算和成功计次逻辑。
5. 最终 data safety 分享/用途、隐私文案和实际路由一起复验。此方案未修改任何市场选择，也未承诺特定地区或年龄的服务已经开放。

“是否可选”逐类型确定：资料对使用学习主功能必需；购买记录由用户选择购买产生；录音导出由用户主动发起。广告数据是否在所有地区都可拒绝，需要最终 UMP/初始化验收，不能由“有一个隐私选项按钮”推断已可选。

## 可直接用于补充隐私说明的事实段落

**安卓账号与购买：**

安卓端可将你明确确认的学习账号绑定到当前设备，以读取会员状态并核实购买。设备保存的登录凭据使用 Android Keystore 保护的加密存储，并排除应用备份。服务器保存用于验证会话、关联订单和权益的必要标识。解除设备绑定只撤销当前绑定，不会删除学习账号、学习历史或订单，也不会删除你的 Google 账号。

**旧版本地资料：**

本地恢复页面读取支持格式的旧版草稿和录音，提供查看、播放和导出。原始资料不会由该页面自动上传或迁移。导出保存到你在系统文件选择器中选定的位置；如果你选择云端文档服务，该服务可能同步导出的副本。功过格网页入口打开原有服务，不携带本地草稿、录音或登录凭据。

**AI 处理补充：**

为生成场景和批改句子，必要的学习内容会发送给 Google Gemini 或 DeepSeek。使用 Gemini 免费额度时，Google 的相应条款允许将输入和输出用于服务改进，并可能由人工审核。请勿在练习中提交敏感、保密或不必要的个人资料。我们不承诺 AI 提供商从不保存或使用提交内容。

广告相关隐私段落必须在最终 SDK 配置确认后补全，说明广告数据、目的、提供商和隐私选择入口；不要把当前隐私页“Web 不展示广告”扩展成整个 Android 包无广告。

## 账号删除：当前不能填“已支持”

现有 `/privacy` 源码明确表示没有自助删除账号；`AuthController` 只有 Google 登录与退出，`UsersController` 只有读取及修改偏好。未发现 JLPT account deletion 请求页面或端点。关于页面提供公开 GitHub issues，不能把公开 issue 当成提交个人资料的私密删除渠道。原生 unlink 已验证只撤销绑定。

Google 要求符合范围的应用提供易找到的应用内删除请求入口及独立可访问的网页渠道。可以是应用内链接到删除网页；网页可采用表单或客服邮箱，但必须实际接受并完成删除请求，说明必要的保留范围。[账号删除要求](https://support.google.com/googleplay/android-developer/answer/13327111?hl=en)

最低收尾工作（不是用户需要回答的技术问题）：

1. 建立固定公开删除说明/请求 URL，显示本应用和开发者身份；未登录或已卸载者可提交请求及完成身份验证。
2. 在账号设置或明确入口链接该页，区分“退出登录”“解除设备绑定”和“删除账号”。
3. 实现并验证请求处理流程：删学习资料、撤销 Web/native sessions、处理 AI job 竞态和第三方请求；按披露的必要目的处理订单保留及反欺诈记录。
4. `PaymentOrder`、`QuotaAccount` 等包含独立 userId 字段，不能仅 `User.delete()` 假定全数据 cascade；旧功过格是另一套账号/数据，删除选择和范围必须明确。不得因删 JLPT 账号擅自取消旧订阅或将未消费旧权益丢弃。
5. 明示备份/日志和必要账务记录保留的实际期限。当前没有已核验的期限，不能在文案虚填“立即清除全部副本”或“保留 30 天”。

删除页面的可用说明句（只有请求入口和履行流程实现后采用）：

> 你可以在本页申请删除日语学习账号及关联学习资料。请按提示验证账号归属。解除设备绑定或退出登录不会删除账号。本页会列明删除范围、处理时间，以及因安全或账务要求需继续保留的数据及期限。功过格旧服务的数据和订阅请按对应服务流程处理；如需一并申请，请在请求中明确说明。

不可直接提交的字段：JLPT 删除 URL、处理时限、保留期限——当前尚未建立，须完成实现/确认后填写真实值。根据根代理后续旧删除页证据，应使用已公开的删除邮箱 `contact@meritledger.org` 作为人工请求渠道基础；仍需明确覆盖 JLPT、身份核验及实际履行流程，不能只把旧邮件地址贴到页面就宣称删除已完成。
