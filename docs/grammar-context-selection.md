# 按语法用途选择练习素材

这次修复取消按等级随机抽取重点词，以及仅按正式／口语套用通用场景的做法。

- `grammar-practice-catalog.ts` 根据仓库内语法教材的解释和例句配置任务；当前覆盖已导入的 40 个 N1 语法用途，匹配必须唯一。未覆盖的语法仍可自由造句，但不附加猜测的场景或词汇。
- 每个任务有自己的候选词集合。词库查询继续检查等级、可见范围、校验状态；再核对词形、读音及义项。收藏与最近接触只影响合格候选的排序，不扩大候选范围。
- 推荐最多两个词。同词同读音只占一项；不足两项或没有合格义项时不补齐。
- `practice-vocabulary.ts` 保存针对具体词典义项的中文教学释义，标记为 `grammar-practice-gloss-zh-v1`；原词典释义和词库记录保留，中文补充存入练习素材快照。
- 新任务采用 `grammar-context-v2`。旧的进行中且尚未提交答案的会话在读取时加锁更新素材；已提交、已完成会话不重写。提示记录、实际用时、评分不变。并发刷新返回同一个当前任务。
- 新的跨场景证据只接受相同选材版本的历史场景，不把旧的无关任务当作新规则的迁移依据。

不修改数据库结构。场景编号与任务在应用分配时写入现有 TrainingScenario 表，会话中保存任务及来源快照。回退应用不会删除新会话记录。

验证：187 项单元测试；35 项真实数据库集成案例（含补测通过的并发刷新案例）；构建、ESLint 和文件行数检查。重点回归为「～かたがた」的礼貌拜访任务、報告／挨拶中文义项、错误读音／义项排除、私人内容隔离、无匹配留空、旧提交保护和场景证据版本隔离。
