# Vocabulary learning v1 — implementation contract

User-approved: per-sense UNKNOWN and PRACTICE lists; manual REMEMBERED authoritative, may coexist with practiceEnabled; contextual sentence production, gradual hints, optional ordering scaffold, independent word evidence and FSRS repetition; detailed word history; unified today entry, no new time budgets or mandatory extra forms. Existing grammar grading and removed extension cards stay unchanged.

## Models (main owns schema/migrations)
VocabularyLearning: id, userId, vocabularyId unique pair; knowledge String UNKNOWN/KNOWN/REMEMBERED, practiceEnabled Boolean, paused Boolean, manualRevision Int, nextReviewAt DateTime?, lastPracticedAt DateTime?, lastOutcome String?, memoryCard Json?, createdAt/updatedAt. Manual UNKNOWN resets to unknown learning (practice false), PRACTICE marks known if unknown and enables practice, REMEMBERED preserves practice and cancels meaning-only due; PAUSE/RESUME and STOP_PRACTICE supported. Preserve histories and memory, do not infer manual status from AI.
VocabularyPractice: id, userId, vocabularyId, learningId, grammarId?, linkedStudySessionId?; status QUEUED/GENERATING/READY/ASSESSING/COMPLETED/FAILED, learningRevision Int, unknownAtStart Boolean, dueAtStart Boolean, counted Boolean false, challenge Json?, answer String?, requestKey String?, hintLevel Int 0, assessment Json?, attempts Int 0, lockedAt?, availableAt DateTime default now, errorCode?, completedAt?, createdAt/updatedAt. Unique unfinished per learning via partial DB index. Worker-only long AI calls, no long DB transactions.

## API (standard {data,meta} envelopes and session auth)
PATCH /vocabulary/:id/learning {action: UNKNOWN|PRACTICE|REMEMBERED|PAUSE|RESUME|STOP_PRACTICE} -> {data: learning}. Visible validated public or owned vocabulary only. Idempotent manual action; repeated REMEMBERED no reschedule. Revisions fence in-flight practices.
GET /vocabulary-learning?list=UNKNOWN|PRACTICE|REMEMBERED|DUE&level=N1&query=&cursor=&limit=30 -> {data: VocabularyEntry[] including learning, meta:{nextCursor}}. Existing GET /vocabulary and /vocabulary/bookmarks include per-user learning (main adds).
GET /vocabulary-learning/summary -> {data:{unknownCount,practiceCount,rememberedCount,dueCount,completedTodayCount}} based on user's timezone. Includes enabled personal lists regardless grammar plan pause. No auto import of bookmarks or all 15k entries.
GET /vocabulary/:id/learning-history?cursor=&limit=20 -> {data: completed practice presentations[],meta:{nextCursor}} owner scoped.
POST /vocabulary-practices {vocabularyId?:string,grammarId?:string,studySessionId?:string} -> {data: public practice}. Omit vocabularyId selects due item, 404 no due. Only marked enabled vocabulary; duplicate calls resume existing. Optional grammar/current session validates ownership/published grammar; other candidates from learned grammar, at most 5. AI may return grammarId:null if unnatural. Optional grammar is practice only and cannot affect official grammar memory.
GET /vocabulary-practices/:id -> {data: public practice}. Poll active job statuses at 1s.
POST /vocabulary-practices/:id/hint {} -> next hint level 1 meaning,2 reading,3 word,4 shuffled chunks. Clamp at 4. Mark server before exposure, monotonic. READY only, reject during ASSESSING. Unknown initial learning already exposed and never counts as independent.
POST /vocabulary-practices/:id/answer {sentence:string(max300),requestKey:UUID} -> {data: public practice}, persist first immutable answer and ASSESSING then worker grades. Replay same key/body returns same; changed answer 409. Client no claimed hint level/result.
POST /vocabulary-practices/:id/retry {} -> FAILED returns queued generation or assessment based on persisted answer; bounded retries, same immutable evidence. Stale GENERATING/ASSESSING jobs recover with lease fencing. Failure never creates successful evidence.

## Public practice presentation
{id,status,vocabularyId,grammarId,linkedStudySessionId,unknownAtStart,hintLevel,errorCode,createdAt,completedAt,promptZh?,grammar?:{id,title},hints:{meaning?:string,reading?:string,word?:string,chunks?:Array<{id:string,text:string}>},learningPreview?:{word,reading,chineseGloss,exampleSentence,exampleFurigana,exampleTranslationZh},answer?:string,result?:{outcome:INDEPENDENT|PROMPTED|INCORRECT|UNVERIFIED,meaningCorrect:boolean|null,readingCorrect:boolean|null,usedTarget:boolean,targetCorrect:boolean|null,explanationZh:string,corrections:Array<{text,replacement,reason}>,correctedSentence,correctedFurigana,correctedTranslationZh},reference?:{sentence,furigana,translationZh},nextReviewAt?}
Only public whitelist. No target Japanese/readings/answer/order/challenge/raw prompt/reference in READY except revealed hints and explicit unknown learningPreview. Linked grammar title intentionally visible as exercise instruction. Hints persisted across refresh/multi-device. COMPLETED shows reference/answer/result. UNVERIFIED (valid alternate expression/no target, or uncertain evidence) is not wrong; no word success and no interval extension. No whole sentence score copied to word; readingCorrect null unless observable reading was tested.

## AI collaborator interface (D owns these two files)
src/vocabulary-learning/vocabulary-ai.schema.ts: exported types Challenge, WordAssessment, AiVocabularyInput, schemas. Challenge {promptZh,meaningHintZh,grammarId:string|null,referenceSentence,referenceFurigana,referenceTranslationZh,chunks:string[]} (reference target word must fit current sense; full readings validated; chunks must join to reference modulo punctuation/whitespace and be unique IDs in public shuffled view). Input {word,reading,chineseGloss,senseKey,glosses,grammars:Array<{id,title,chineseExplanation,connectionRule?}>,previousPrompts:string[]}.
VocabularyAiService.generate(input:AiVocabularyInput):Promise<Challenge>
VocabularyAiService.assess(input:AiVocabularyInput, challenge:Challenge, sentence:string):Promise<WordAssessment>
Assessment {usedTarget:boolean,targetCorrect:boolean|null,meaningCorrect:boolean|null,readingCorrect:null,explanationZh,corrections:[{text,replacement,reason}],correctedSentence,correctedFurigana,correctedTranslationZh}. Independent of whole grammar correctness, allows conjugation/appropriate spelling, abstains on uncertain sense. Valid alternative expression/no target -> usedTarget false. Corrected sentence need not force target if original alternate is natural. Reuse existing Gemini/DeepSeek config/fallback and HTTP timeout helper; no new providers. Missing/invalid score doesn't become success. Generated scene must not leak Japanese target in prompt or hint1; reject invalid output and leave retryable failure. No runtime translation calls.

## Scheduling/evidence
A owns FSRS (ts-fsrs existing 0.9 retention,365d cap, no fuzz) serialized memoryCard. Only first due attempt on different local date and current manualRevision can advance. Unknown initial study and hints/order are assisted; no automatic manual knowledge promotion/demotion. INDEPENDENT=Good, PROMPTED=Hard, INCORRECT=Again, UNVERIFIED=no scheduling success. Same-day/early repetitions do not inflate stability or postpone existing due; failures can shorten appropriately. A known REMEMBERED word with practice off never gets rescheduled by an old result. No deletions on status changes. Paused items excluded today. History includes examples and feedback; per-sense IDs retained.
