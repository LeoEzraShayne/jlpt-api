# JLPT 学习业务升级：本地验收与使用说明

## 已实现的业务

1. **N1～N4 各保留一个当前计划**：进行中和暂停都占用本级别的当前计划位置；新建其他级别不会更改主目标。计划可独立调整、暂停、恢复，旧计划保留历史。
2. **共享每日时间**：主目标默认 80%，基础级别合计 20%，可调整、可互借。已用时间和进行中的预计用时计入预算，刷新不会重新发放时间。基础积压不会阻止主目标份额内的新学。
3. **复习与掌握证据**：沿用 FSRS，默认保持率 90%、最长间隔 365 天。新版掌握要求不同日期的连续三次到期复习，首次评分至少 80、目标语法正确、未看提示、自评记得，且有有效换场景验证、稳定期估计至少 30 天。掌握后仍保留复习日期。
4. **场景训练与批改**：理解、替换、组合、迁移逐步推进；简单但正确的句子不会因不够复杂而扣分。批改展示内容回应、原句说明／纠错、拓展示例和后续练习。辅助语法、词汇只记接触或使用，不共享目标语法分数。
5. **词汇与私人资料**：支持来源查询、生词收藏、导入预览、逐条校验和提交。分级属于参考资料，不冒称官方词表或历年真题频率。
6. **个人表达库**：可保存检查正确的原句、修正版、拓展示例和备注。正式复习隐藏参考表达，主动打开计为提示，不额外生成表达复习队列。

## 建议的试用顺序

- 在“管理各级别计划”确认主目标 N1、每日总分钟数和 80/20 比例，再建立需要的基础级别计划。
- N1 默认“系统学习”；基础默认“查漏补缺”。基础级别没有已学记录时，先到语法库标记“需加强”，系统会安排首次检查。这不会直接标记已学或掌握。
- 从今日任务进入练习，按场景完成表达，查看批改后选择记忆自评；不要为了凑掌握次数在同一天反复刷分。
- 在批改卡片收藏常用表达；到“词汇与表达库”查询词义、管理收藏和核对私人导入。
- 暂停所有计划后仍能查看历史、手动练习，不会重新进入新用户引导。
